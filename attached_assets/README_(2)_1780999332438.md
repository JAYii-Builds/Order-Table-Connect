# Prime Property Building Maintenance — Project Overview

A professional property maintenance business website for **Prime Property Building Maintenance**, a Coventry-based company. Built with React, TypeScript, Express, and PostgreSQL — featuring a public-facing site with 8 pages and a fully functional admin dashboard.

---

## Live Site Pages

| Route | Description |
|---|---|
| `/` | Animated hero landing page with service highlights |
| `/services` | Full services listing — individual cards with icons and descriptions |
| `/emergency` | 24/7 emergency call-out page |
| `/gallery` | Photo gallery of completed work |
| `/about` | Company story, values, and team |
| `/reviews` | Customer testimonials |
| `/contact` | Quote request form |
| `/privacy` | Privacy policy |
| `/admin` | Admin dashboard login |

---

## Site Features

### Public Site
- **Animated Hero** — Typewriter effect cycling through services, background image carousel, Framer Motion transitions
- **Services Section** — 9 individual service cards fetched from the database (Bathroom Fit-Outs, Kitchen Fit-Outs, Tiling, Plastering, Carpentry, Painting & Decorating, Plumbing, Building Works, Emergency Works)
- **Emergency Banner** — Sticky red top bar with direct phone link; floating emergency button in nav
- **Gallery** — Visual showcase of completed projects
- **Contact / Quote Form** — Saves inquiries directly to the database
- **WhatsApp Button** — Floating click-to-chat button on all public pages
- **Reviews Page** — Customer testimonial showcase

### Design
- Dark navy and gold brand palette (`#0a0f1e` / `#FFD700` / `#cc0000`)
- Fully responsive — mobile, tablet, desktop
- Sticky header with scroll-aware transparency
- Custom glass-card UI components with Tailwind CSS v4
- Framer Motion animations throughout

## Admin Dashboard (`/admin`)

A secure management suite for staff to control all site content.

### Dashboard Features
- **Login** — JWT authentication via httpOnly cookies; forced password change on first login
- **Services Management** — Full CRUD: add, edit, reorder, and delete services
- **Gallery Management** — Upload and manage project photos
- **Testimonials Management** — Add and edit customer reviews
- **Inquiry Management** — View all quote requests submitted via the contact form; reply directly via email
- **Audit Log** — Full record of every admin action (who did what and when)

## Running the Project

The project runs as two parallel services:

| Workflow | Command | Port |
|---|---|---|
| `Start application` | `PORT=5000 pnpm --filter @workspace/prime-property run dev` | `5000` |
| `API Server` | `PORT=8080 pnpm --filter @workspace/api-server run dev` | `8080` |

Frontend API calls are proxied from `5000 → 8080` via Vite's dev proxy.

### Useful Commands

```bash
# Install all dependencies
pnpm install

# Push DB schema changes (dev only)
pnpm --filter @workspace/db run push

# Regenerate API hooks from OpenAPI spec
pnpm --filter @workspace/api-spec run codegen

# Full typecheck
pnpm run typecheck

# Production build
pnpm run build
```

## Architecture Notes

- **Contract-first API** — `lib/api-spec/openapi.yaml` is the single source of truth; Orval generates both React Query hooks and Zod validators from it. Run codegen after any spec change.
- **Flat routing** — All routes defined flat in `App.tsx` with `useLocation` to switch layouts. Do not nest `<Switch>` components in wouter — causes blank renders.
- **DB seeded on push** — Running `pnpm --filter @workspace/db run push` applies the schema. Sample data (services, admin user) is seeded on first run.
- **Drizzle reserved keyword** — The `order` column must always be quoted in raw SQL: `"order"`.
